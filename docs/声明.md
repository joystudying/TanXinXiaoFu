本文件说明：这个项目是什么、不能用来做什么、数据去了哪里、密钥谁来负责、有哪些已确认的局限。

最后更新：2026-11-01 · 对应分支 `integrate`

---

## 一、项目性质

**这是一个训练模拟器，不是心理咨询工具，也不是学生筛查工具。**

- 虚拟学生由大模型扮演，所有回应都是生成的，**不指向任何真实的人**
- 使用对象是高校辅导员和承担学生工作的教师，用于**谈话技能练习**
- 系统**不做诊断**，不输出临床判断，不评估真实学生的心理状态
- 危机专项仅用于「识别与转介」的**模拟演练**：不拨打电话、不发送消息、不触发任何校园应急流程

**明确禁止的用法**：

- 把模型对虚拟学生的判断，当作对真实学生的评估依据
- 把复盘评分当作教师考核、职称或绩效的证据
- 未经授权，把真实学生的信息输入本系统

## 二、数据去了哪里

### 2.1 存在本机的内容

| 数据 | 位置 | 说明 |
|---|---|---|
| 案例与私有设定 | `data/tanxin.db` | 私有设定只在服务端，不下发前端 |
| 训练会话与对话文本 | `data/tanxin.db` | 用于复盘与历史记录 |
| 实时语音的音频 | **不落盘** | 只在内存中转发，不写入磁盘 |
| 配置与密钥 | `.env` | 已被 `.gitignore` 忽略，不进仓库 |

**音频不保存**是刻意设计：语音里可能包含情绪、语气等敏感信息，存下来风险大于收益。
如果将来要做回听功能，必须单独设计授权与留存期限。

### 2.2 会离开本机的内容

这一条必须说清楚：**对话内容会发送给第三方模型服务**。

| 环节 | 数据去向 | 发送内容 |
|---|---|---|
| 扮演学生的模型 | DeepSeek 官方 API | 案例公开资料、私有设定、历史对话 |
| 实时语音 | 火山引擎 | 麦克风音频流、会话配置 |
| 按轮朗读 | 微软在线音色（edge-tts） | 学生要说出的那句话 |
| 本地离线识别 | **不出本机** | 由你自己部署的 FunASR 处理 |

**这意味着**：如果你所在学校对数据出境、第三方处理有规定，**必须先走审批**，再决定是否启用实时语音与在线合成。
纯文字 + 本地 FunASR 的组合可以做到「对话内容不离开本机」。

### 2.3 日志

- 服务端不记录完整对话内容
- 不记录密钥
- 500 错误会打印堆栈到控制台，用于排障，不含请求正文

## 三、密钥与账号

### 3.1 谁负责

**每个使用者用自己的账号和密钥。** 本项目不转售、不代充、不共享任何凭证。

- DeepSeek 的 key：按你的调用量计费，账单在你的账号下
- 火山引擎的凭证：同上，试用额度用完后开始计费

### 3.2 存放与访问

- 密钥只写在**本机**的 `.env`
- 「接入 AI」页面修改配置的接口**只允许回环地址**（127.0.0.1 / ::1）访问，公网请求返回 403
- 页面上**从不回显**密钥，只显示「已配置 / 未配置」
- 提交到仓库前会扫描 `sk-` 前缀与已知凭证，仓库内零密钥

### 3.3 泄露了怎么办

1. 立刻去对应控制台**吊销并重新生成**
2. 检查 `.env` 是否被误提交（`git log -p -- .env`）
3. 如果已经推到远端，仅删除文件不够——**历史里还在**，需要改写历史或更换密钥

> 开发过程中真实发生过一次：备份的 `.env` 被误 `git add` 进提交。
> 发现后从提交中移除、补进 `.gitignore`，并确认远端从未收到。这个项目对此保持零容忍。

## 四、复盘评价的效力

**评价结果不构成权威结论，量规尚未定稿。**

- 五维评价（共情引导、思想引领、问题解决、临场应变、语言表达）参考高校辅导员谈心谈话评审表
- **具体分档、扣分条件、多证据合并规则仍在待确认**，当前只能用简化量规
- 系统设计上要求每条评价绑定教师原话与轮次，引用校验失败时不得作为有效证据
- 依据不足的维度标记为「依据不足」，**不记零分、不补造依据**
- 危机处置行为与一般谈话维度分开呈现，一般维度的高分不能抵消危机流程的关键缺项

## 五、已确认的技术局限（实测结论）

以下不是猜测，是做过对照实验后得到的结论：

| 局限 | 实测情况 |
|---|---|
| 实时语音无法指定台词 | 500 ChatTTSText 在端到端会话里不产生音频；模型始终自主应答 |
| 无法关闭模型自主输出 | `output_mod` 的三种取值均被服务端忽略；省略 dialog 配置也不生效 |
| 情绪只能会话级控制 | 502 注入情绪不稳定、无梯度、多次注入会衰减 |
| 情绪控制的有效手段 | 只剩人设提示词、音色、语速（实测：换成低落描述后语速 −11%、基频 −3%，两组分布不重叠） |
| 外放会有回声 | 麦克风会拾取喇叭声音；已在播放期做静音与打断阈值处理，最稳的是戴耳机或「按住说话」 |
| 实时对话不落库 | 目前实时通话的对话文本未写入 `turns` 表，刷新即丢失（待补） |
| 语音识别依赖浏览器 | Chrome / Edge 自带识别；其他浏览器需自部署 FunASR |

## 六、第三方服务与条款

| 服务 | 用途 | 是否必需 | 备注 |
|---|---|---|---|
| DeepSeek | 扮演学生 | 文字对练必需 | 按 token 计费 |
| 火山引擎（豆包语音） | 实时双工语音 | 可选 | 有试用额度，之后按音频时长计费 |
| edge-tts | 语音合成 | 可选 | 免费，用的是微软在线音色通道 |
| FunASR | 本地识别 | 可选 | 阿里开源，可完全离线 |

使用这些服务时，**各自的服务条款与数据处理政策同时生效**，本项目的声明不能替代它们。

## 八、内容审核

- 案例是虚构人物，来源类型与审核状态记录在 `cases.review_status`
- 当前仅 1 个案例，状态为 `draft`（草稿）
- **危机专项内容必须经专业人员审核**后才能作为正式训练内容
- 评价量规同样需要负责人确认

未经审核的内容，只作为界面占位或内部演示，不作为已通过的训练材料。
