# 公告 · 新用户接入指南

> **这个项目不内置任何 AI 密钥。** 克隆下来后需要你自己申请并填写，否则文字对练用不了、实时语音是灰的。
>
> 这不是设置麻烦，是刻意的：密钥一旦进代码库就会泄露，谁拿到都能刷你的账单。

---

## 一、先说清楚：哪部分要钱，哪部分不要

| 功能 | 要申请吗 | 花钱吗 |
|---|---|---|
| 文字对练（聊天框） | 要：DeepSeek API Key | 按用量，很便宜 |
| 实时语音（真双工，可以打断） | 要：火山引擎 AppID + Access Token | 有试用额度，之后按音频时长计费 |
| 按轮语音的朗读 | 不要，edge-tts 免费 | 免费 |
| 本地离线识别（可选） | 不要，但要装 FunASR + 约 1GB 模型 | 免费 |

**只填 DeepSeek 也能完整跑起来**：文字对练、浏览器语音识别、朗读都正常，只是没有「实时通话」那种可以随时打断的双工体验。

## 二、三步接上

### 第 1 步：复制配置文件

```powershell
copy .env.example .env
```

`.env` 已经被 `.gitignore` 忽略，不会进仓库，可以放心填。

### 第 2 步：申请两份密钥

#### DeepSeek（文字对练必需）

1. 打开 <https://platform.deepseek.com>
2. 注册并登录
3. 左侧「API Keys」→ 新建，复制生成的 `sk-` 开头的字符串
4. 填进 `.env`：

```
DEEPSEEK_API_KEY=sk-你复制的那串
```

#### 火山引擎（实时语音必需）

1. 打开 <https://console.volcengine.com/speech/app>
2. 注册账号，**完成实名认证**（个人认证即可；不认证不能开通任何服务）
3. 点「创建应用」，填个名字（只能用英文数字下划线中划线，4–30 个字符）
4. 创建后在「编辑」里勾选 **豆包端到端实时语音大模型**，确定
5. 会弹「确认后将开启免费试用版，并赠送试用额度」——点确认，这一步**不收费**
6. 进入该应用的服务详情页，拉到最下方「服务接口认证信息」，复制 **APP ID** 和 **Access Token**

填进 `.env`：

```
VOLC_APP_ID=你的APPID
VOLC_ACCESS_TOKEN=你的AccessToken
```

> Access Token 在新版控制台可能显示成 `************`。
> 如果看不到内容也没有复制按钮，切换到「旧版」控制台查看，或用浏览器的开发者工具看接口返回。

### 第 3 步：启动

```powershell
cd 项目目录
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r backend\requirements.txt
.\.venv\Scripts\python.exe -m uvicorn app.main:app --app-dir backend --port 8000 --no-server-header
```

打开 <http://127.0.0.1:8000/>。

## 三、怎么判断接好了

**服务端自检。** 启动时如果缺 DeepSeek Key，会直接退出并打印：

```
启动失败：
  - 缺少 DEEPSEEK_API_KEY：请把 key 写进 ...\.env 的 DEEPSEEK_API_KEY 一行
  - 数据库不可用（...）
```

看到这个不是程序坏了，是提醒你还没填。

**页面自检。** 打开谈话页：

- 底部提示「未检测到模型密钥」→ DeepSeek 没填对
- 「实时通话」按钮是灰的 → 火山两个值没填，或没开通端到端实时语音
- 打字能收到回复 → 文字链路已通

**接口自检。** 浏览器打开 <http://127.0.0.1:8000/api/capabilities>，看两个字段：

```json
"llm": {"ready": true},
"realtime": {"ready": true}
```

## 四、常见卡点

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 启动直接退出，提示缺 DEEPSEEK_API_KEY | `.env` 没填或文件名不对 | 确认文件名是 `.env` 不是 `.env.txt` |
| `llm.ready` 是 true，但对话报 502 | key 无效或余额为 0 | 去 DeepSeek 控制台确认 key 和余额 |
| 实时通话按钮灰的 | 火山没实名、没开通服务、或值填错 | 回控制台检查服务是否在「运行中」 |
| 点了实时通话，提示拿不到麦克风 | 浏览器权限被拒 | 点地址栏左侧的锁图标，允许麦克风 |
| 有回音、老是打断自己 | 外放时喇叭声音进了麦克风 | **戴耳机**，或改用「按住说话」 |
| 学生说话声音很小 | 火山输出电平偏低 | 默认已经加了 +9.5dB 增益，仍偏小可在 `frontend/js/realtime.js` 调 `GAIN` |
| 端口 8000 被占用 | 上次的进程没关 | 换端口：`--port 8001` |

## 五、三条安全提醒

1. **不要把 `.env` 提交到仓库。** 它已经在 `.gitignore` 里，别手动 `git add -f`。
2. **不要把密钥贴进聊天、截图或 issue。** 泄露了立刻去控制台吊销重发。
3. **火山那个 `X-Api-App-Key` 是官方公开常量**（`PlgvMymc7f3tQnJ6`），写在代码里不是泄露，别和安全扫描结论混淆。

## 六、费用大概多少

- **DeepSeek**：一轮对话（几百字上下文）通常不到一分钱。练二十轮也就几毛。
- **火山实时语音**：按音频时长计费，试用额度通常够开发和小规模演示。
- **edge-tts 和 FunASR**：完全免费。

正式对外使用前，建议先看两家的计费页面，按实际用量估一次。
